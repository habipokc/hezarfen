# Phase 6 — Advanced features: trails, playback and geofence drawing

**Goal:** selecting an aircraft shows its last 30 minutes as a line that keeps growing live; a
"History" mode replays a past window (up to 2 h) from `/api/playback` with play/pause, a time
slider and 1×/10×/60× speed, interpolating between frames; users draw polygons on the map with
terra-draw, name and save them (`POST /api/geofences/`), toggle and delete zones; a live
`geofence_event` raises a toast, lands in the event list and makes its polygon blink.
Backend endpoints already exist (Phase 3); this phase is mostly frontend.

## Data flow

```
mode = live                               mode = history
useLiveSocket (enabled)                   useLiveSocket disabled (socket closed, badge "Paused")
useLiveAircraft → aircraft + tails        usePlayback: GET /api/playback?start&end&bucket
useTrack: GET /track + live extension       → buildTimeline(frames) (per-aircraft samples)
                                            → rAF clock, ≤ 20 draws/s:
                                               sampleAt(t) → aircraft source
                                               tailsAt(t)  → tails source
                                               trackUntil(selected, t) → track source
useGeofences: GET /api/geofences/ → geofences source (all zones, inactive dimmed)
useDrawPolygon: terra-draw polygon mode → name form → POST → reload
geofence_event (live) → event list + toast + feature-state blink on the polygon
```

## Decisions to log

- terra-draw 1.36.0 + `terra-draw-maplibre-gl-adapter` 1.4.1 (plan named it; small, framework-free).
- Short tails for every aircraft: on (toggleable "Trails"), built client-side from the live
  stream, 2 min window; decided after measuring `setData` with a large synthetic load.
- Playback: REST frames, client-side clock; bucket chosen from the window length (~360 frames);
  linear interpolation of lon/lat (great-circle error is negligible at 10–20 s gaps), heading
  along the shorter arc; no interpolation across gaps > 3 buckets; draws capped at 20/s.
- History mode closes the socket (plan: "suspend"); returning to live reconnects and the new
  snapshot repopulates the store.
- Geofence refresh after own CRUD (refetch); no WS message for `geofences.changed` (single-user app).
- Client pre-check of drawn polygons with the server's limits for instant feedback; the server
  stays authoritative.
