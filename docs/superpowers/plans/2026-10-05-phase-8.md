# Phase 8 — HTMX ops panel, quality and delivery

Goal: a server-rendered operations panel at `/ops/`, scheduled retention, a complete CI
pipeline, delivery docs (README, DEMO) and a verified clean-clone start.

## 1. Retention core (TDD)

- `tracking/retention.py`: `prune_positions(days, batch_size)` deletes in short batches
  (`DELETE … WHERE id IN (SELECT id … WHERE ts < cutoff LIMIT n)`) so the ingest insert path
  never waits on one huge transaction. Returns `PruneResult(deleted, cutoff, seconds)`.
  `record_run(result, trigger)` / `last_run()` keep the last run in Redis (`ops:retention:last`),
  best effort.
- `prune_positions` command uses it (same output).
- `ops/schedule.py`: `run_every(job, interval, stop)` loop: runs once at start, then every
  `interval` seconds until `stop` is set; a failing run is logged, the loop survives. Tested
  with a fake stop event.
- `maintenance` management command + compose service (backend image, own dev tag, watchfiles in
  dev, heartbeat-file healthcheck). `RETENTION_INTERVAL_SECONDS` (default 3600) in `.env.example`.

## 2. Ops panel (Django templates + HTMX, vendored htmx 2.0.11)

- Move `fetch_ingest_metrics` / `ingest_status` to `ops/ingest.py`; add pure
  `ingest_summary(metrics, now)` (TDD) for the template: status, mode, poll age, credits, batch,
  errors, rejected total.
- Views (`ops/views.py`, `ops/urls.py`, mounted at `/ops/`):
  - `GET /ops/` full page (ingest, events, geofences, retention)
  - `GET /ops/ingest`, `GET /ops/events` partials, polled `every 5s` (only while the tab is visible)
  - `POST /ops/geofences/<id>/active` with an explicit `active` value (idempotent, not a toggle);
    returns the updated row; publishes `geofences.changed` after commit
  - `POST /ops/retention` runs the prune and returns the retention block
- CSRF token via `hx-headers` on `<body>`; `hx-confirm` on retention; a banner when polling fails.
- Positions overview without full scans: `reltuples` estimate, oldest row by `id`.
- nginx: `/ops` → `/ops/` redirect; mount the `nginx/` folder instead of the single file (D-082).
- SPA: an "Ops" link in the panel header.
