# Faz 0 — Uygulama planı (İskelet, altyapı ve sözleşme)

- **Tarih:** 2026-10-05
- **Kaynak:** PLAN.md §7 Faz 0 + environment design spec (port 8800, `learn/` ayrı repo, faz sonunda dur).

## Hedef

`make up` ile 7 servis (db, redis, backend, relay, ingest, frontend, nginx) healthy olur; `curl localhost:8800/api/health` ve `localhost:8800/` yanıt verir; Django, Go ve Vite kodu değişince container restart olmadan reload olur.

## Görevler

1. **Kök dosyalar:** `.gitignore`, `.env.example`, `CLAUDE.md`, `PROGRESS.md`, `docs/DECISIONS.md`, kısa `README.md`.
2. **Compose:** `docker-compose.yml` (prod benzeri: `target: prod`, healthcheck'ler, `depends_on: service_healthy`, `name: hezarfen`, `container_name` yok) ve `docker-compose.override.yml` (dev: `target: dev`, bind mount, reload komutları, dev healthcheck'leri).
3. **backend:** Python 3.14-slim + GDAL/GEOS/PROJ apt paketleri. Minimal Django projesi (`hezarfen`), `ops` app'i (`/api/health`: DB + PostGIS + Redis kontrolü), `tracking` app'i içinde placeholder `relay` management command'ı (Redis'e bağlanır, heartbeat dosyası yazar). Dev: `uvicorn --reload` (watchfiles/inotify). Test: pytest-django ile health testi.
4. **ingest:** Go 1.27 modülü; `cmd/ingest` placeholder HTTP sunucusu (`/healthz`, `/metrics`), `-healthcheck` alt komutu, slog, graceful shutdown. Dockerfile: `dev` (air) ve `prod` (distroless) target'ları. Test: `httptest` ile handler testi.
5. **frontend:** Vite + React + TS (strict) placeholder sayfa; HMR nginx üzerinden (`hmr.clientPort`). Prod target: build + nginx 5173'te statik servis. Test: vitest ile küçük bir saf fonksiyon testi; ESLint flat config.
6. **nginx:** `/api`, `/admin`, `/ops`, `/ws` (upgrade), `/tiles` (statik `data/tiles`), `/` (frontend, HMR için upgrade).
7. **Makefile:** `up`, `down`, `logs`, `test`, `lint`, `seed`, `dem`, `record` (+ yardımcılar).
8. **Dokümanlar:** `docs/ICD.md` (§6 tamamı), `docs/ARCHITECTURE.md` (Mermaid).
9. **CI:** `.github/workflows/ci.yml` — go, python (PostGIS service), frontend, docker build job'ları.
10. **Kapanış:** testler → smoke test + kabul kriterleri → `learn/00`, `learn/01` (learn reposunda commit) → `PROGRESS.md` → `phase-0` commit + tag → dur.
