# Phase 7 — Raster: DEM, hillshade and terrain sampling

**Goal:** `make dem` builds, from the Copernicus DEM GLO-90, an analysis COG (EPSG:4326) and
hillshade XYZ tiles (zoom 6–11); nginx serves the tiles and the map shows them as a toggleable
raster layer with an opacity slider; `GET /api/terrain/elevation` samples the COG; the aircraft
details show terrain elevation, AGL and a "low flight" badge.

## Pipeline (`scripts/prepare_dem.sh`, `gdal` tools container)

```
download 1°×1° GLO-90 COG tiles for the bbox (cached; 404 = all-sea tile)
  └─ fallback: synthetic_dem.py (Gaussian hills, sea = 0) when nothing downloads
gdalinfo (inspect) → gdalbuildvrt mosaic.vrt
  ├─ gdal_translate -projwin bbox -of COG (EPSG:4326, native grid, nodata −32767) → dem_4326_cog.tif
  └─ gdalwarp EPSG:3857 bilinear → gdaldem hillshade (z = 1/cos(mid lat))
       → shade_rgba.py (black/white + alpha, flat = transparent) → gdal2tiles --xyz 6–11
       → data/tiles/hillshade/ + meta.json (source, zooms, bounds)
```

## Decisions to log

GDAL tools image; GLO-90 (90 m) and download layout; sea and nodata handling; resampling
choices (native grid for the COG, bilinear for 3857); Mercator z-factor; RGBA hillshade;
bilinear sampling with nodata fallback; AGL definition (GNSS altitude − DEM, no geoid
correction); low-flight rule (airport_buffer zones, selected aircraft only); file-change reload.
