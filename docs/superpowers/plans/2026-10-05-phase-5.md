# Phase 5 — Frontend core: React, TypeScript and MapLibre

**Goal:** `localhost:8800` shows a MapLibre map of the Marmara region with live aircraft that
move every update, rotate with their heading and are coloured by altitude. Panning re-subscribes
the WebSocket with the viewport bbox, so only visible aircraft are streamed. Reference layers
(provinces, airports, geofences) can be toggled; clicking an aircraft opens a detail panel fed by
REST. Desktop: side panel. Mobile (375 px): bottom sheet. Contract: ICD §6, §7.

## Data flow

```
useLiveSocket (one WebSocket, backoff, watchdog)
   │ subscribe(bbox) on open and on every moveend
   ▼ parsed ServerMessage (discriminated union)
useLiveAircraft
   ├─ snapshot/delta → LiveStore: Map<icao24, Feature>, newest ts wins
   ├─ throttle(1 s) → map.getSource('aircraft').setData(featureCollection)
   │                 + React state: count, selected aircraft's live record
   └─ geofence_event → recent events list
MapLibre instance lives in a useRef (never React state); layers are added once on 'load'.
```

## Decisions to log

- UI copy in English (code-adjacent; the owner reads English UI fine, learn files stay Turkish).
- Basemap: OpenFreeMap `dark` (data layers stand out); style JSON fetched with a 5 s timeout,
  fallback is an inline style (background + demotiles glyphs) so data layers still render.
- Subscribe bbox = viewport padded 10 % (no pop-in at edges), clamped and rounded to 4 decimals;
  an identical bbox is not re-sent.
- Aircraft icon: SDF image drawn on a canvas at runtime (no asset pipeline, colour by expression).
  Hover/selected highlight is a circle layer whose stroke opacity reads `feature-state`
  (feature-state cannot drive layout properties such as `icon-size`).
- `setData` throttled to 1 s on the client too (snapshot + delta can arrive back to back).
- Socket: backoff 0.5 s × 2ⁿ capped at 30 s with full jitter; attempt counter resets after a
  snapshot (not on open, so an accept-then-close loop still backs off); watchdog closes the socket
  after 45 s without any frame (3 missed heartbeats).
