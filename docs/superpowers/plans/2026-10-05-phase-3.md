# Phase 3 — Django REST API (plan)

Goal: every ICD §7.2 Phase 3 endpoint serves meaningful JSON/GeoJSON while synthetic data
flows; OpenAPI + Swagger work; pytest covers every endpoint.

## Dependencies (pinned, current stable 2026-10-05)

djangorestframework 3.18.1, djangorestframework-gis 1.3.0, drf-spectacular 0.30.0,
shapely 2.1.2. No django-filter: the few query filters are parsed by hand with the same
validation helpers, so every 400 has the ICD §7.1 shape.

## Layout

- `hezarfen/api/` — shared API plumbing
  - `errors.py`: `ApiError(code, message, details)`, DRF exception handler → ICD §7.1
    (`{"error": {"code", "message", "details"}}`), JSON 404 for unknown `/api/` paths,
    `OperationalError` → 503 `unavailable`.
  - `params.py` (pure, TDD): `parse_bbox`, `parse_unix`, `parse_int`, `parse_bool`,
    `parse_csv_choices`.
  - `fields.py`: `UnixTimeField` (datetime ↔ Unix seconds).
  - `urls.py`: router + paths + schema/docs + catch-all.
- `tracking/api.py`: aircraft live, detail (province + nearest airport, KNN then re-rank
  by metric distance), track (`ST_MakeLine(geom ORDER BY ts)`), playback (`DISTINCT ON`
  per bucket), stats (DB counts + ingest `/metrics`).
- `geofencing/validation.py` (pure, TDD): shapely validity → `make_valid` → single polygon,
  vertex limit, area limits (local equal-area approximation), must intersect region bbox.
- `geofencing/api.py`: `GeofenceViewSet` (CRUD, `?active=`), publishes
  `geofences.changed/v1` on commit; `GeofenceEventList` (cursor pagination, `since`,
  `geofence`).
- `reference/api.py`: provinces (`ST_Simplify`, coordinate precision), airports (`?type=`).
- Settings: `REST_FRAMEWORK` (no authentication classes → no CSRF on the API, AllowAny),
  `SPECTACULAR_SETTINGS`, `REGION_BBOX` from `BBOX_*`, `INGEST_METRICS_URL`.

## Tests

- Unit (no DB): params, polygon validation, error handler shape.
- Integration (PostGIS): bbox filter (outside aircraft excluded, stale excluded), detail
  province/nearest airport, track ordering, playback buckets + window limit, geofence CRUD
  + validation errors + publish on commit, events pagination/filters, provinces simplified,
  airports filter, stats with fake ingest metrics, OpenAPI schema validates without warnings.

## Smoke

curl every endpoint through nginx (`:8800`) with synthetic data; `/api/aircraft/live`
timing < 100 ms; Swagger UI loads; gzip for large playback responses via nginx.
